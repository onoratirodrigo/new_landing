# Slides del carrusel de Etman Market

Guardá acá las capturas del e-commerce que se muestran en el carrusel del bloque "Etman Market" de la landing.

Nombres esperados (referenciados en `src/data/marketSlides.ts`):

- `slide-1.png` — Home de Etman Market (banner del Mundial / destacados / promos)
- `slide-2.png` — Listado de productos por patente
- `slide-3.png` — Promociones vigentes

Recomendaciones:
- Relación 16:10 o 16:9 (el carrusel usa `aspect-[16/10]` y recorta desde arriba).
- Mínimo 1600px de ancho para que se vea nítido en pantallas grandes.
- PNG o JPG; si pesan mucho, comprimir con TinyPNG/Squoosh.

Para agregar, sacar o reordenar slides, editar `src/data/marketSlides.ts`.
