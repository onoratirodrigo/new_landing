# Video del Hero

Colocá acá el archivo `hero.mp4` (o `hero.webm`) que se reproduce en la sección Hero.

Si el archivo tiene otro nombre, ajustá la ruta en `src/data/site.ts` (`heroVideo`).

Recomendaciones:
- Resolución máxima 1920×1080 (FullHD)
- Bitrate moderado (~3-5 Mbps) para no saturar la carga inicial
- Sin audio (el video se reproduce muteado)
- Duración 8–20 segundos en loop
- Idealmente exportar también un `hero-poster.jpg` (frame inicial) en `/public/images/` para mostrar antes de que cargue el video
